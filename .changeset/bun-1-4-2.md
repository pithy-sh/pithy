The kit is built and tested on Bun 1.4.2. Running Pithy under Bun now takes 1.4 or later; Node is unchanged.

An import that will not resolve now gets one remedy from every surface — `pithy.config.ts`, a capability loader, and the vite plugin alike — and is told to install only when installing can help. A bare import of an installed package with no entry there — an `exports` map with no `"."`, or none an import can use — is told so, by the package's name, rather than to install it. One whose `package.json` names an entry that is not on disk is told the package is unbuilt or its install is broken, and to rebuild or reinstall that package. The vite plugin reads Vite's own wording for both, so a config importing `@pithy-sh/core` or an unbuilt package is no longer told the config threw. `@pithy-sh/core/src/error/unresolved` is the one classifier (`unresolvedImport`, `nodeModulesProbe`, `importingPackage`), and `@pithy-sh/core/src/naming/packageName` the one `packageOf`. `unresolvedKind` and `unresolvedSpecifier` are gone from `@pithy-sh/core/src/error/cause`, and `importingPackage` moved to `unresolved`.

Workers AI runs again from outside a Worker. `runModel` posts to `/ai/run/@cf/...` with the model's slashes intact, and refuses a malformed model name before sending anything. A D1 query over REST is sent once and never retried, so a slow `CREATE TABLE` no longer fails as `table already exists`. The CLI hands wrangler the Worker's directory as `--cwd`, so `pithy deploy` works in a project that runs wrangler through `npx`.

An at-rest rotation whose first read-back misses waits and tries again, instead of failing. On Cloudflare a `WorkflowStep` is an RPC stub, and `classifiedSteps().sleep` asked it for a method named `call`. It calls the step's own `sleep` now. Support classification calls the AI binding the same way. `pithy vector provision` waits up to five minutes for a metadata index, and calls it live only after three reads in a row list it under its own name and type. Ten seconds and one read were not enough: Vectorize took 97s on one run and more than 120s on the next.
