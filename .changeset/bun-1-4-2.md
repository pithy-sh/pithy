The kit is built and tested on Bun 1.4.2. Running Pithy under Bun now takes 1.4 or later; Node is unchanged.

An import that will not resolve now gets one remedy from every surface — `pithy.config.ts`, a capability loader, and the vite plugin alike — and is told to install only when installing can help. `@pithy-sh/core/src/error/unresolved` is the one classifier (`unresolvedImport`, `nodeModulesProbe`, `importingPackage`), and `@pithy-sh/core/src/naming/packageName` the one `packageOf`. `unresolvedKind` and `unresolvedSpecifier` are gone from `@pithy-sh/core/src/error/cause`, and `importingPackage` moved to `unresolved`.

Workers AI runs again from outside a Worker. `runModel` posts to `/ai/run/@cf/...` with the model's slashes intact, and refuses a malformed model name before sending anything. A D1 query over REST is sent once and never retried, so a slow `CREATE TABLE` no longer fails as `table already exists`. The CLI hands wrangler the Worker's directory as `--cwd`, so `pithy deploy` works in a project that runs wrangler through `npx`.
